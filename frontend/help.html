1. Introduction

Qu’est-ce que CHAT ?
CHAT (Clinique Hôtelière et Actions Touristiques) est un système prototype intégré permettant la gestion centralisée de plusieurs infrastructures : clinique, laboratoire, imagerie médicale, hôtel, agence touristique et parc roulant.

Composants du système :

  • 🌐 Plateforme web : pour les professionnels (admin, direction, médecins, etc.)
  • 📱 Application mobile (Android) : pour les patients et personnels mobiles (chauffeurs, infirmiers)

Objectif principal : offrir une solution unifiée pour la gestion médicale, hôtelière et touristique avec des interfaces adaptées à chaque profil.

2. Connexion au système

🌐 Plateforme web

  1. Accéder à : https://clinique-hoteliere-et-actions.onrender.com
  2. Cliquer sur “Espace Personnel”
  3. Choisir un profil (médecin, infirmier, admin, etc.)
  4. Utiliser les identifiants du tableau des comptes démo (section 3)
  5. Cliquer sur “Se connecter”

📱 Application mobile

  1. Ouvrir l’application CHAT
  2. Appuyer sur “Prendre RDV” ou menu → “Espace Personnel”
  3. Dans l’écran “WhatsApp Connect”, deux options :
    • Connexion normale : saisir un numéro WhatsApp → recevoir un code → valider
    • Connexion démo (recommandée pour le jury) : choisir un profil dans la liste déroulante → appuyer sur “Connexion avec compte démo” → connexion immédiate
